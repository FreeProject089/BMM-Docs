# Install BMM

1. Download the latest release for your OS.
2. Run the installer.
3. Launch BMM.

That's it — there's no account to create and nothing to configure before first launch.

## Which build?

**Stable** unless you have a reason. In **Settings → Updates** you can opt into
**pre-releases**: they get fixes first and bugs first. That's a real trade, which is why
it's a toggle and not the default.

## Auto-update

On by default. BMM checks, tells you, and updates itself. You can turn it off in the same
place — but then update by hand, because a mod manager that's a year behind the repos it
reads will eventually disagree with them.
